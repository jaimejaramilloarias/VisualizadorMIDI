# Material de referencia

Esta carpeta contiene prototipos o experimentos útiles para orientar la versión
2, pero no se cargan desde `index.html` ni forman parte de la aplicación
principal.

`midi-nowline-visualizer/` fue copiado desde Documentos. Su implementación se
mantiene intacta para estudiar el movimiento de notas, el uso de Canvas y la
NOW LINE antes de decidir qué conceptos migrar.
